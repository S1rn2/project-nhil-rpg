# Project Nhil RPG for Minecraft Java

An action-adventure RPG layer for Minecraft Java 1.21.11 on Fabric. It adds ruin building blocks, landmark discovery, Nhil levels and ranks, elite monsters, a rune-powered sword, a wayfinder compass, a rune altar and rune tonics, all in a vanilla visual style. Everything works in single player and on dedicated multiplayer servers.

## What's Included
- The `nhil` command tree: status, landmarks, ranks, progress, plus operator grant and relic tools
- Player progress persisted through a data attachment, so levels survive relogging, restarts and death
- Elite monster variants, marked once when a mob loads and rewarded when it dies
- All gameplay runs server side, with a small optional client readout for level and experience

## Build
```bash
./gradlew build
```
